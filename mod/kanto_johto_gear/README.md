# Kanto + Johto Gear 1.0.0-beta.1

This unofficial dual-screen companion mod supports Kanto in compatible
Generation I hosts and both Johto and postgame Kanto in the matching custom
Gen2Recomped Android host.

The Mods screen uses the combined **Kanto + Johto Gear** name. The compact
companion header displays **KANTO GEAR** in Gen1 and **JOHTO GEAR** in Gen2.

## Requirements

- A matching companion-enabled Android host.
- `Kanto-Johto-Gear-Mod-1.0.0-beta.1.zip` imported through **Mods**.
- Your own supported Pokemon Red, Blue, Yellow, Gold or Silver ROM.
- A dual-display Android device for the intended companion experience.

No ROM, save file or ROM-extracted game data is included.

## Gen2 install

1. Back up existing saves.
2. Install the matching Kanto + Johto Gear Gen2 host APK.
3. Import your own supported Pokemon Gold or Silver ROM.
4. Open **Mods**, choose **Import mod .zip**, and select
   `Kanto-Johto-Gear-Mod-1.0.0-beta.1.zip`.
5. Enable **Kanto + Johto Gear** and start the game.

The forked host installs separately from upstream Gen2Recomped under
`com.wireproof.kantojohtogear`. Separate Android apps do not automatically
share saves, settings or imported ROM caches.

## Generation II behavior

- Johto and Kanto landmark maps with postgame region switching.
- Morning, day and night encounter information.
- All 16 badges and Generation II HM gates.
- Generation II's 14 PC boxes and numeric item aliases.
- Headbutt, Rock Smash, Sweet Scent, Whirlpool and Waterfall field actions.

## Beta notice

Automated mod, host, rendering, pointer and Android bridge tests pass. Physical
AYN Thor testing was not available during development, so real-device display
ordering, touch mapping, hotplugging and live screen swapping remain beta.

This project is an AI-assisted compatibility fork maintained by
[wireproof](https://github.com/wireproof). It is not an official Pokemon,
Nintendo, Gen1Recomp or Gen2Recomped release.
